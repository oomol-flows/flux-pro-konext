# Flux Pro Kontext

基于 Flux Pro Kontext API 的 AI 图像转换工具,用于高级视觉内容处理和生成。

## 概述

Flux Pro Kontext 是一个强大的 OOMOL 包,提供与 fal-flux-pro-kontext API 的无缝集成。它使您能够通过简单地提供源图像和描述性提示词来使用先进的 AI 模型转换和增强图像。该包处理从提交请求到检索处理结果的整个工作流程。

## 功能特性

- **简单的图像转换**:使用自然语言提示词转换图像
- **异步处理**:高效地提交请求并轮询结果
- **强大的错误处理**:全面的错误消息和重试机制
- **进度跟踪**:结果轮询期间的实时进度更新
- **灵活配置**:可自定义轮询间隔和超时设置

## 功能模块

### 任务模块

#### 1. 提交 Kontext 请求

此模块向 Flux Pro Kontext API 提交图像处理请求。

**功能说明:**
- 接收源图像 URL 和转换提示词作为输入
- 自动通过 OOMOL 平台进行身份验证
- 将请求提交到 Flux Pro Kontext API
- 返回用于跟踪处理任务的唯一请求 ID

**使用场景:** 当您想要启动图像转换任务时使用此模块。例如,您可以提供一张风景图片,并要求 AI "将其转换为日落场景" 或 "添加戏剧性光照"。

**输入参数:**
- `image_url` (字符串): 要处理的图像的 URL
- `prompt` (文本): 所需转换的描述

**输出:**
- `request_id` (字符串): 用于跟踪处理任务的唯一标识符

#### 2. 轮询 Kontext 结果

此模块从先前提交的请求中检索处理结果。

**功能说明:**
- 监控图像转换任务的处理状态
- 自动重试直到结果准备就绪或超时
- 在轮询过程中报告进度
- 完成时返回处理后图像的 URL

**使用场景:** 在提交请求后使用此模块等待并检索转换后的图像。它处理了检查状态和等待完成的所有复杂性。

**输入参数:**
- `request_id` (字符串): 从提交 Kontext 请求模块返回的 ID
- `max_attempts` (数字,可选): 超时前的最大轮询尝试次数(默认:60)
- `poll_interval` (数字,可选): 每次状态检查之间的秒数(默认:2)

**输出:**
- `image_url` (字符串): 处理/转换后图像的 URL
- `status` (字符串): 请求的最终状态(例如 "success"、"completed")

### Subflow 工作流

Subflow 是预构建的工作流,将多个任务模块组合成可重用的简化接口。

#### 1. 文件 Kontext 编辑

上传本地图像文件并使用 Flux Pro Kontext AI 进行编辑。

**功能说明:**
- 自动将本地图像文件上传到云存储
- 使用您的提示词提交图像转换请求
- 轮询结果并下载编辑后的图像
- 将最终图像保存到指定位置

**输入参数:**
- `file` (文件): 要编辑的本地图像文件
- `prompt` (文本): AI 模型的编辑指令
- `saved_path` (保存路径,可选): 保存编辑后图像的路径

**输出:**
- `saved_path` (字符串): 成功下载的编辑后图像的路径

**使用场景:** 非常适合批量处理本地图像或处理计算机上的文件。只需选择图像文件,描述您希望如何编辑,即可将结果保存到本地。

#### 2. URL Kontext 编辑

使用 Flux Pro Kontext AI 编辑在线图像。

**功能说明:**
- 直接接收在线图像 URL
- 提交转换请求
- 轮询结果并返回编辑后的图像 URL

**输入参数:**
- `image_url` (字符串): 要编辑的图像 URL
- `prompt` (文本): AI 模型的编辑指令

**输出:**
- `image_url` (字符串): 编辑后图像的 URL

**使用场景:** 非常适合处理已托管在线的图像或需要链式进行多次转换。输出 URL 可以直接使用或传递给其他工作流模块。

## 基本用法

### 使用 Subflow 快速开始(推荐)

最简单的入门方式是使用预构建的 subflow:

**处理本地图像:**
1. 将 "文件 Kontext 编辑" subflow 添加到工作流
2. 选择本地图像文件
3. 输入转换提示词(例如 "让它看起来像复古照片")
4. (可选)选择保存结果的位置
5. 运行工作流 - 编辑后的图像将自动保存

**处理在线图像:**
1. 将 "URL Kontext 编辑" subflow 添加到工作流
2. 提供图像 URL
3. 输入转换提示词
4. 运行工作流 - 获取编辑后图像的 URL

### 使用任务模块进行高级操作

如需更多控制,可以使用单独的任务模块构建自定义工作流:

1. **准备图像**:确保您有要转换的图像的公开访问 URL
2. **添加提交模块**:使用 "提交 Kontext 请求" 模块并提供:
   - 您的图像 URL
   - 描述性提示词(例如 "转换为水彩画风格")
3. **添加轮询模块**:连接 "轮询 Kontext 结果" 模块以接收请求 ID
4. **获取结果**:轮询模块将输出转换后图像的 URL

### 工作流配置示例

**使用 Subflow(简单):**
```
[本地图像文件] → [文件 Kontext 编辑 Subflow] → [保存的图像路径]
[您的提示词]
```

**使用任务模块(高级):**
```
[您的图像 URL] → [提交 Kontext 请求] → [request_id] → [轮询 Kontext 结果] → [转换后的图像 URL]
                 [您的提示词]                          [可选设置]
```

两种方式都会自动:
- 通过 OOMOL 平台进行身份验证
- 提交您的转换请求
- 监控处理状态
- 返回最终转换后的图像

## 集成

此包与其他 OOMOL 包集成:
- **upload-to-cloud** (v0.0.5): 在文件 Kontext 编辑 subflow 中用于将本地图像上传到云存储
- **downloader** (v0.1.1): 在文件 Kontext 编辑 subflow 中用于下载编辑后的图像结果

## 身份验证

身份验证通过 OOMOL 平台自动处理。这些模块使用平台的内置令牌系统,因此您无需手动提供 API 密钥。

## 错误处理

该包包含强大的错误处理机制:
- **网络错误**:使用可配置的尝试次数自动重试
- **API 错误**:来自服务的详细错误消息
- **超时处理**:可自定义的超时设置
- **数据缺失**:清晰的验证消息

## 技术细节

### API 端点

- **提交**: `https://fusion-api.oomol.com/v1/fal-flux-pro-kontext/submit`
- **结果**: `https://fusion-api.oomol.com/v1/fal-flux-pro-kontext/result/{request_id}`

### 依赖项

该包使用标准 Python 库:
- `requests`: 用于 API 通信的 HTTP 客户端
- `oocana`: OOMOL 平台上下文和身份验证

### 性能

- **默认超时时间**:120 秒(60 次尝试 × 2 秒间隔)
- **可配置轮询**:根据您的需求调整 `max_attempts` 和 `poll_interval`
- **进度报告**:轮询期间的实时百分比更新
