# Flux Pro Kontext

基于 Flux Pro Kontext API 的 AI 图像转换工具,用于高级视觉内容处理和生成。

## 概述

Flux Pro Kontext 是一个强大的 OOMOL 包,提供与 fal-flux-pro-kontext API 的无缝集成。它使您能够通过简单地提供源图像和描述性提示词来使用先进的 AI 模型转换和增强图像。该包处理从提交请求到检索处理结果的整个工作流程。

## 功能特性

- **简单的图像转换**:使用自然语言提示词转换图像
- **异步处理**:高效地提交请求并轮询结果
- **强大的错误处理**:全面的错误消息和重试机制
- **进度跟踪**:结果轮询期间的实时进度更新
- **灵活配置**:可自定义轮询间隔和超时设置

## 功能模块

### 1. 提交 Kontext 请求

此模块向 Flux Pro Kontext API 提交图像处理请求。

**功能说明:**
- 接收源图像 URL 和转换提示词作为输入
- 自动通过 OOMOL 平台进行身份验证
- 将请求提交到 Flux Pro Kontext API
- 返回用于跟踪处理任务的唯一请求 ID

**使用场景:** 当您想要启动图像转换任务时使用此模块。例如,您可以提供一张风景图片,并要求 AI "将其转换为日落场景" 或 "添加戏剧性光照"。

**输入参数:**
- `image_url` (字符串): 要处理的图像的 URL
- `prompt` (文本): 所需转换的描述

**输出:**
- `request_id` (字符串): 用于跟踪处理任务的唯一标识符

### 2. 轮询 Kontext 结果

此模块从先前提交的请求中检索处理结果。

**功能说明:**
- 监控图像转换任务的处理状态
- 自动重试直到结果准备就绪或超时
- 在轮询过程中报告进度
- 完成时返回处理后图像的 URL

**使用场景:** 在提交请求后使用此模块等待并检索转换后的图像。它处理了检查状态和等待完成的所有复杂性。

**输入参数:**
- `request_id` (字符串): 从提交 Kontext 请求模块返回的 ID
- `max_attempts` (数字,可选): 超时前的最大轮询尝试次数(默认:60)
- `poll_interval` (数字,可选): 每次状态检查之间的秒数(默认:2)

**输出:**
- `image_url` (字符串): 处理/转换后图像的 URL
- `status` (字符串): 请求的最终状态(例如 "success"、"completed")

## 基本用法

### 简单工作流

1. **准备图像**:确保您有要转换的图像的公开访问 URL
2. **添加提交模块**:使用 "提交 Kontext 请求" 模块并提供:
   - 您的图像 URL
   - 描述性提示词(例如 "转换为水彩画风格")
3. **添加轮询模块**:连接 "轮询 Kontext 结果" 模块以接收请求 ID
4. **获取结果**:轮询模块将输出转换后图像的 URL

### 工作流配置示例

以下是两个模块如何协同工作:

```
[您的图像 URL] → [提交 Kontext 请求] → [request_id] → [轮询 Kontext 结果] → [转换后的图像 URL]
                 [您的提示词]                          [可选设置]
```

工作流自动执行:
- 通过 OOMOL 平台进行身份验证
- 提交您的转换请求
- 监控处理状态
- 返回最终转换后的图像

## 集成

此包与 `upload-to-cloud` 包(v0.0.5)集成,实现无缝的云存储和图像 URL 管理。

## 身份验证

身份验证通过 OOMOL 平台自动处理。这些模块使用平台的内置令牌系统,因此您无需手动提供 API 密钥。

## 错误处理

该包包含强大的错误处理机制:
- **网络错误**:使用可配置的尝试次数自动重试
- **API 错误**:来自服务的详细错误消息
- **超时处理**:可自定义的超时设置
- **数据缺失**:清晰的验证消息

## 技术细节

### API 端点

- **提交**: `https://fusion-api.oomol.com/v1/fal-flux-pro-kontext/submit`
- **结果**: `https://fusion-api.oomol.com/v1/fal-flux-pro-kontext/result/{request_id}`

### 依赖项

该包使用标准 Python 库:
- `requests`: 用于 API 通信的 HTTP 客户端
- `oocana`: OOMOL 平台上下文和身份验证

### 性能

- **默认超时时间**:120 秒(60 次尝试 × 2 秒间隔)
- **可配置轮询**:根据您的需求调整 `max_attempts` 和 `poll_interval`
- **进度报告**:轮询期间的实时百分比更新
